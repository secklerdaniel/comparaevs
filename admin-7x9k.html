Pipeline Prospecção Prioridade

Pipeline de Monetização

Ideias de monetização categorizadas por dificuldade técnica de implementação no site — da mais simples (reaproveita estrutura existente) à mais complexa (feature nova do zero).

Fácil

Botão de lead para concessionária

"Quero receber proposta" no card do veículo → grava lead no Supabase. Reaproveita estrutura existente.

Formulário de orçamento de instalação

Form simples (nome, telefone, CEP, tipo de imóvel) pra captar lead de instalação de wallbox.

Cupom / loja recomendada de wallbox

Reaproveita 100% a estrutura da página Loja — só trocar/adicionar produtos e links de afiliado.

Afiliado de assinatura de EV

Banner/link de afiliado pra Localiza Meoo, Movida, Unidas etc. — mesmo padrão de banner já existente.

Médio

Afiliado de app de recarga

Tecnicamente é só um banner — a dificuldade real é comercial: achar rede com programa de afiliado self-service.

Simulador de financiamento verde

A calculadora de economia é só JS — fica médio por precisar de rota serverless (Vercel function) pra cotação real sem expor chave de API.

Simulador de seguro (form disfarçado)

Cotação real exige integração com corretora — versão simplificada é form bonito que capta dado pra cotação manual.

Difícil

Mapa de eletropostos + destaque pago

Feature nova do zero: precisa base de dados de eletropostos própria, integração de mapa (Maps/Mapbox) e lógica de destaque pago por estabelecimento.

Gargalo nas ideias de afiliado/CPL não é técnico — é comercial: exige tráfego comprovado antes que montadoras/bancos/corretoras topem negociar direto.

Por onde começar

  1. Grupo IESA — local (RS), facilita reunião presencial, e representa BYD + GWM + Volvo numa única conversa.
  2. EZVolt e Tupi — CPOs mais avançados em interoperabilidade hoje, mais prováveis de já ter programa de afiliados estruturado.
  3. Localiza Meoo — maior player de assinatura, processo de afiliados provavelmente mais maduro que concorrentes menores.
  4. Tokio Marine / Minuto Seguros — produto de seguro para EV já existe, é só achar o canal de distribuição certo.
  5. Bancos (BB, BV, Santander, Itaú) — deixar para depois: programas de crédito verde tendem a ser negociados via parcerias institucionais maiores, ciclo de fechamento mais longo.
